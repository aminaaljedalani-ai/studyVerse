Website title StudyVerse
Website category Educational website
Problem statement Students often struggle to organise their study time, stay focused and find a suitable place to study. These tools are usually spread across different apps and websites. StudyVerse brings them together in one friendly place, with study spots that are relevant to students in Bahrain.
Target audience School, college and university students in Bahrain who want to plan their studies, improve their focus and find good places to study.
Project objectives
  • Help students plan and organise their study time.
  • Support focus and wellbeing with a Pomodoro timer, mood matcher, stress relief and break ideas.
  • Help students discover study spots in Bahrain.
  • Provide a consistent, responsive website that works on desktop, tablet and mobile in light and dark mode.
  • Use AI tools responsibly and document how they were used.

Requirement Analysis

Functional Requirements

  • User registration: a form on the Home page collecting first name, last name, mobile number and email.
  • Form validation: first and last name at least 3 characters, mobile number exactly 8 digits, valid email format, with clear success and error messages.
  • Navigation system: one shared navigation bar linking all seven pages.
  • Login demo: a login window with a welcome message (front-end only).
  • Theme switch: a moon/sun button that switches between light and dark mode.
  • Study planner: tools to plan study time.
  • Focus tools: Pomodoro timer, Mood Matcher, Stress SOS and Break Generator.
  • Study Spot Finder: cards with information about study spots.

Non-Functional Requirements

  • Performance: lightweight pages with no heavy frameworks beyond Bootstrap, so pages load quickly.
  • Accessibility: semantic HTML, one clear heading structure per page, labelled form fields, alt text on images and readable colour contrast in both themes.
  • Security: input is validated before use, and no passwords are collected. The site is a front-end demo and sends nothing to a server.
  • Usability: simple layout, consistent cards, clear buttons and the same navigation on every page.
  • Responsiveness: layouts adapt to desktop, tablet and mobile using Bootstrap's grid and CSS media queries.
  • Maintainability: shared CSS variables and shared files keep the design consistent across all pages.
