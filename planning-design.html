Behind the Design

Our Design Approach

StudyVerse is a student-focused website designed to make studying more organized, productive and enjoyable. Our design combines practical study tools with a cozy, hand-drawn desk theme.

We use sticky-note cards, soft colors, handwritten fonts, clear headings and consistent navigation. The aim is to create a welcoming experience where students can plan their work, improve their focus and explore study spots in Bahrain.

Design Decisions

Simple Layout

Content is divided into clear sections so students can find information without confusion.

Easy Navigation

The same navigation bar appears on every page. The active link indicates the current page.

Consistent Cards

Sticky-note cards create visual consistency and separate different tools and topics.

Clear Buttons and Headings

Buttons use action-based labels such as Start, Pause, Reset and Surprise Me. Headings describe each section clearly.

Consistent Spacing

Bootstrap spacing utilities, containers and grid classes create balanced layouts.

Light and Dark Themes

Shared CSS variables allow colors to change without rebuilding the page structure.

Responsive Design Plan

The website is designed to adapt to desktop, tablet and mobile screens using Bootstrap 5 and CSS media queries.

Desktop

Larger screens use multi-column layouts to display tools side by side.

Example: the Pomodoro Timer and Mood Matcher share one row.

Tablet

Grid columns adjust to available width. Spacing and cards remain readable.

Bootstrap classes such as col-md-6 help organize content.

Mobile

Cards stack vertically, navigation collapses into a menu and large elements scale down.

Media queries adjust spacing and typography for smaller screens.

Bootstrap Grid and Media Queries

The Bootstrap container, row, col-md-6 and col-lg-7 classes organize content responsively.

CSS media queries such as @media (max-width: 767px) allow us to adjust padding, typography and layouts on narrow screens.

Accessibility

StudyVerse uses semantic HTML elements, meaningful headings, labeled inputs, descriptive buttons and keyboard-accessible controls.

The responsive layout helps students use the website on different devices. Light and dark modes offer different visual preferences, while feedback messages help users understand interactive features.
